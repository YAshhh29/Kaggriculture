# Experiment Journal

Raw runs live under ignored `artifacts/`. This directory records the conclusions
that should survive on GitHub.

Use one Markdown file per promoted or instructive rejected hypothesis. Include:

- hypothesis and controlling code path;
- exact command and seed set;
- incumbent and candidate hashes;
- win/loss result and mechanism metrics;
- reason for promotion or rejection;
- fresh seeds consumed by the decision.

Rejected experiments are useful when they eliminate an attractive but harmful
idea. For example, globally choosing the nearest planting target reduced route
distance but lost 6-14 because it broke coherent value-aware crop placement.
